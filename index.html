ระบบสารสนเทศภูมิศาสตร์และแดชบอร์ดระบาดวิทยา - พัฒนาเพื่อการวิเคราะห์ทางสาธารณสุข

พร้อมรองรับการเผยแพร่บน GitHub Pages และใช้งานแบบ Offline/Static Web Application

ขั้นตอนการนำไฟล์นี้ไปลงบน GitHub Pages

1. สร้าง Repository บน GitHub:

เข้า GitHub.com แล้วสร้าง Repositoryใหม่ ตั้งชื่อตามต้องการ (เช่น covid-dashboard)

2. อัปโหลดไฟล์ HTML:

นำไฟล์ HTML นี้ไปตั้งชื่อว่า index.html แล้ว Upload ขึ้นใน Root Directory ของ Repository

3. เปิดใช้งาน GitHub Pages:

ไปที่ Settings > Pages ใน Repository แล้วเลือก Branch: main (หรือ master) แล้วกด Save

4. พร้อมเข้าใช้งาน:

ภายใน 1-2 นาที แดชบอร์ดจะพร้อมใช้งานที่ URL: https://[your-username].github.io/[repo-name]/
